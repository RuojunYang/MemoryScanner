# WPF 内存扫描器

一个 Windows 用户态内存扫描工具，支持选择进程、精确整数扫描、再次筛选以及修改选中地址。

## 支持范围

- 1、2、4、8 字节整数
- 有符号和无符号整数
- Windows 小端序精确值扫描
- 已提交且可读内存区域
- 后台扫描、进度显示和取消
- 写入后立即回读校验

这是精简实现，不包含未知初始值、增大/减小值、浮点数、指针链、调试器、驱动或反作弊绕过。结果列表显示前 10,000 项，但再次扫描会使用完整候选集合；为避免耗尽内存，单次扫描最多保留 10,000,000 个匹配。

## 运行

需要 Windows x64 和 .NET 8 Desktop Runtime 或更高版本。

```powershell
dotnet run --project .\src\MemoryScanner\MemoryScanner.csproj -c Release
```

1. 从顶部列表选择目标进程并点击“打开进程”。
2. 选择整数类型，输入当前十进制数值，然后点击“首次扫描”。
3. 在目标程序中改变数值，输入新值并点击“再次扫描”来缩小结果。
4. 选择结果，输入新值并点击“写入并校验”。

普通权限无法打开高权限或受保护进程时，请关闭程序后以管理员身份启动终端或生成的程序。目标进程退出后需要重新选择。

## 构建与测试

```powershell
dotnet build .\内存扫描.sln -c Release
dotnet test .\tests\MemoryScanner.Tests\MemoryScanner.Tests.csproj -c Release
```

测试包含整数边界与字节序校验，以及针对独立辅助进程的跨 1 MB 分块扫描、再次扫描、写入和回读验证。

## 使用边界

仅扫描和修改你拥有或明确获准测试的进程。程序只使用标准 Windows 用户态 API，不尝试规避操作系统权限、反作弊或受保护进程机制。
